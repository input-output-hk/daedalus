Two judgements worth naming.

**The copy states the disclosure rather than implying it.** "The index you choose
learns which of these tokens this wallet holds" is the sentence the PRD's privacy
argument depends on being visible, and it has its own case so a later copy edit
cannot quietly remove it. The Koios description says what is sent, which is
identifiers and nothing else, and what happens to the answer, which is that it is
confirmed locally before it is stored. Both are true of what `task-033` and
`task-034` build, and both would become false if either changed. That coupling is
worth stating: this copy is a claim about the implementation, not a description
of the setting.

**Sixteen untranslated messages.** They land in `ja-JP.json` carrying the `!!!`
marker, so a Japanese user reads this page in English until a translation round
covers it. That is the same state the eleven messages from phases 1 to 5 are in,
and the marker is what records it.

What this task does not establish: that the selection changes anything. It does
not yet. The page reads and writes a value the pointer client will take in
`task-033`, and until then choosing a different index changes nothing a user can
observe.

Decision: approved
