## Why Chosen Now

`task-003.dependencies` is `[task-001]` and `task-001` is complete. `task-007` depends on both this

compiled it. It is the cautionary case the PRD cites for replacing the barrel with a glob: a story
file went dead with every check green.

## Implementation Approach

1. There is no non-deletion source edit. Nothing imports the story, nothing outside the directory
   imports its components, and no barrel names either. The deletion list is written and handed off
   first rather than last, because every other step depends on the files being gone.
2. After the removals, regenerate the i18n artifacts with the CI `node_modules` rather than a host
   tree:

       nix build --no-link --print-out-paths .#internal.x86_64-linux.node_modules
       export NODE_PATH=$out/node_modules PATH=$out/node_modules/.bin:$PATH
       formatjs extract 'source/**/*.{ts,tsx}' --ignore='**/*.d.ts' \
         --format='translations/formatter.js' --extract-source-location \
         --out-file='translations/messages.json'
       node -r @swc-node/register ./translations/translation-runner.ts

   These are the two halves of `yarn i18n:manage` at `package.json`, run against the same
   dependency tree the check uses. Expect exactly six ids to disappear from four files and nothing
   else to move.
3. Confirm the regeneration removed only what it should: six ids gone from each of the four
   artifacts, and the diff confined to those lines.
4. Stage everything before running a check, then verify the tree: 18 deletions, four modifications,
   nothing untracked outside `.agent/`.
5. Regenerate the sidebar and diff against the `task-001` baseline. Expect the two `StakingChart`
   registrations gone, the title gone, and `UNREACHABLE` at 0.
6. Run `compile`, `lint`, `storybook` and `i18n` as flake checks. `i18n` is not in the task entry's
   acceptance and is run because this task changes its inputs.
7. Land it as one signed commit on `docs/storybook-modernization-plan`.
